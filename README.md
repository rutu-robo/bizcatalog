## 🛠️ Ringkasan Quick Start

### Backend (Go 1.22+ Gin)
```bash
cd backend
go run cmd/server/main.go
# Server berjalan di port 8080 (http://localhost:8080)
```

### Frontend (React 18 + Vite + TypeScript)
```bash
cd frontend
npm install
npm run dev
# Vite dev server berjalan di http://localhost:5173
```
